Known limits: a payment settles one whole bill; R2 reason-for-delay and the tax-rate effect are not built; R3 assumes equal instalments and counts only this year's booked instalments (a moratorium, step-up, balloon, interest inside an instalment or an earlier-year start would make the split wrong) and asks only whether the sanction letter and schedule are on file, with no "where" field; the Bank Rate history is not applied; interest is not approvable until a rate is stored; the new Convex functions are text-tested only.
- Known limits, named on purpose:
  - `answers:detail` is a public read (entries, narrations, answer, snapshot); acceptable on dev only.
  - `books()` in convex/answers.ts reads every entry on each detail and decide; it will not scale past the Convex read limit.
  - Any visitor can trigger the global hourly lockout by sending wrong passcodes.
  - `decide` guards against a changed answer, not against changed books.
  - The AI is dev-only and Gate B makes no AI call: the question is code-built. Before the AI words an R1 question, the verifier must also enforce neutral wording on the question part (the R1 checks cover the context statements only).
  - Current ratio before and after (RULES_v1 R1) is not built; only debt-equity.
  - R1 goal and options changed (decision #40), so the M1 R1 eval inputs no longer match what was scored; M1 stays closed as "marks not met".
  - R2 and R3 flags are listed with sizes but have no questions or outcomes yet; R3 size is the closing balance.
  - Many on-screen headings and button labels are working words, not yet chosen by Swapnil.
  - convex/answers.ts is only text-tested (no Convex runtime here); the dev run covered record and detail, then decide.

- Audit fixes (21 Oct 2026): one `loadBooks` for every Convex module; one shared save and approve path (convex/decisions.ts) used by R1, R2 and R3, with per-rule approval rules in shared/; the passcode lockout and the write steps now run in tests against a fake database; failure records older than two hours are deleted; a rate date must be today in India; the gap list warns when it was built with older rules (shared/rule-set-version.ts: bump it when a rule changes); the three screen containers share one hook.
